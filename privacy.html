Privacy Policy

Last updated: October 1, 2026

This policy describes how Wonders to Explore Uploader ("the application") handles data. The application is an internal tool operated by the owner of the YouTube channel Wonders to Explore and is used only by that person.

YouTube API Services

The application uses the YouTube API Services. Use of the application is subject to the Google Privacy Policy and the YouTube Terms of Service.

Data the application accesses

  • Basic information about the authorized YouTube channel (name, ID, statistics).
  • The channel's own videos, playlists, captions and comments, in order to upload and update the channel owner's content.
  • YouTube Analytics reports for the channel's own videos (views, watch time, traffic sources).

How data is used and stored

Data is used only to upload and manage the channel owner's own content and to review its performance. Authorization tokens and any retrieved data are stored only on the channel owner's personal computer. The application has no servers, no user accounts, no advertising and no analytics of its own.

Sharing

The application does not sell, share, transfer or disclose any user data to third parties.

Retention and deletion

Retrieved data is kept only as long as needed to manage the channel and can be deleted at any time by deleting the local files. Access can be revoked at any time from the Google security settings page, which stops all further access.
